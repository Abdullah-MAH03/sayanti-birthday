# Sayanti Birthday

A standalone, dependency-free birthday greeting page.

## Open the page

Open `index.html` in a web browser. The page and its animations work without a
development server or package installation. An internet connection is only
needed for the optional Google Font.

## Personalize it

- The page uses `sayanti-photo.jpeg` for the portrait. Replace that file to use
  another photo.
- Update the text inside the `birthday-note-copy` element in `index.html` to
  change the birthday note.
- Select **Cakes here** to open the animated cake and balloons. Tap a balloon to
  pop it, or tap the candle to blow it out.
- Edit `styles.css` to customize the colors, layout, or animations.
